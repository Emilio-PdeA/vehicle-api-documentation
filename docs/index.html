Vehicle Inventory API

Developer-focused documentation for retrieving vehicle inventory, viewing individual vehicle details, and running structured searches across a large vehicle dataset.

About this project. This is an anonymized portfolio reconstruction. Proprietary company names, internal environments, source-system mappings, and sensitive identifiers have been removed or generalized.

Authentication

Requests use Bearer token authentication. Include your access token in the Authorization header.

Authorization: Bearer YOUR_ACCESS_TOKEN

Never expose access tokens in client-side code or public repositories.

Endpoints

Three operations cover the core inventory workflow: browse, inspect, and search.

GET/vehicles/listBrowse paginated vehicle inventory with lightweight filters.
GET/vehicles/detailsRetrieve detailed information for a specific vehicle.
POST/vehicles/searchRun complex searches using structured filters, ranges, sorting, and aggregations.
GET/vehicles/list

List vehicles

Returns a paginated collection of vehicles matching the supplied filters.

Query parameters

ParameterTypeRequiredDescription
pageintegerYesZero-based page number.
marketCodestringNoMarket filter.
statusstringNoAvailability filter.

Example request

GET /v1/vehicles/list?page=0&marketCode=ES&status=available
Authorization: Bearer YOUR_ACCESS_TOKEN

Example response

{
  "info": { "status": "success", "returnedRecords": 10, "totalRecords": 42, "page": 0 },
  "data": [
    { "id": "VEH-0001842", "modelName": "Example SUV", "marketCode": "ES", "status": "available" }
  ]
}
GET/vehicles/details

Get vehicle details

Retrieves detailed information for a specific vehicle using an identifying query parameter.

Query parameters

ParameterTypeRequiredDescription
vehicleIdstringNo*Unique vehicle identifier.
configurationIdstringNo*Vehicle configuration identifier.

* Supply the identifier required by the integration context.

Example request

GET /v1/vehicles/details?vehicleId=VEH-0001842
Authorization: Bearer YOUR_ACCESS_TOKEN

Example response

{
  "info": { "status": "success", "returnedRecords": 1, "totalRecords": 1, "page": 0 },
  "data": {
    "id": "VEH-0001842",
    "configurationId": "CFG-78421",
    "modelName": "Example SUV",
    "engineConcept": "hybrid",
    "onlineAvailable": true
  }
}
POST/vehicles/search

Search vehicles

Run a structured search across vehicle inventory. The request supports pagination, identifiers, product attributes, availability, date and price ranges, sorting, and optional aggregations.

Request headers

HeaderTypeRequiredDescription
AuthorizationstringYesBearer access token.
accept-languagestringNoPreferred response language.
Content-TypestringYesUse application/json.

Request body

FieldTypeDescription
pageintegerZero-based page number.
perPageintegerMaximum records returned per page.
orderIdstring[]Filter by order identifiers.
configurationIdstring[]Filter by configuration identifiers.
marketCodestring[]Filter by market.
vehicleIdstring[]Filter by vehicle identifiers.
productGroupstring[]Filter by product group.
modelNamestring[]Filter by model.
bodyTypestring[]Filter by body type.
engineConceptstring[]Filter by powertrain concept.
visibilitystring[]Filter by visibility state.
availabilitystring[]Filter by availability state.
onlineAvailableboolean[]Filter for online availability.
aggregationsstring[]Optional result groups.
sortByobjectSort field and direction.
actualFinalDateobjectInclusive date range.
grossListPriceobjectMinimum and maximum price.
configurationCodeobjectMust, should, and must-not configuration values.
isLegacybooleanFilter legacy records.

Example request

POST /v1/vehicles/search
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json

{
  "page": 0,
  "perPage": 20,
  "marketCode": ["ES"],
  "bodyType": ["SUV"],
  "engineConcept": ["hybrid"],
  "onlineAvailable": [true],
  "grossListPrice": { "min": 30000, "max": 60000 },
  "sortBy": { "fieldName": "estimatedDeliveryDate", "sortType": "ASC" }
}

Example response

{
  "info": {
    "status": "success",
    "returnedRecords": 2,
    "totalRecords": 14,
    "page": 0
  },
  "data": [
    {
      "id": "VEH-0001842",
      "configurationId": "CFG-78421",
      "marketCode": "ES",
      "modelName": "Example SUV",
      "bodyType": "SUV",
      "engineConcept": "hybrid",
      "grossListPrice": 43797.95,
      "currency": "EUR",
      "onlineAvailable": true
    }
  ],
  "aggregations": {
    "vehicleBodyGroup": [
      { "code": "SUV", "description": "SUV" }
    ]
  }
}

Errors

The API uses standard HTTP status codes to indicate whether a request succeeded or failed.

StatusMeaningTypical cause
400Bad RequestInvalid query parameters or search criteria.
401UnauthorizedMissing or invalid access token.
403ForbiddenThe authenticated client lacks permission.
404Not FoundThe requested vehicle does not exist.
500Internal Server ErrorUnexpected server-side failure.

Example error

{
  "type": "invalid_request",
  "detail": "The supplied search criteria could not be processed."
}
