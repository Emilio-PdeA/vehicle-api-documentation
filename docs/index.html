Vehicle Inventory API

A task-oriented REST API for retrieving vehicle availability, detailed vehicle information, and filtered search results.

Portfolio project. This documentation is an anonymized reconstruction created to demonstrate technical writing, API information architecture, and developer-focused communication.

Authentication

Requests use bearer-token authentication. Include your access token in the Authorization header.

Authorization: Bearer YOUR_ACCESS_TOKEN
Vehicles

List available vehicles

Retrieve a paginated collection of vehicles. Optional filters can narrow results by market, sales channel, or online-sales readiness.

GET/vehicles/list
Query parameters
pageintegerrequired
Zero-based page number.
marketCodestring
Optional market filter.
salesChannelstring
Optional sales-channel filter.
ecommerceReadyboolean
Return only vehicles ready for an online sales flow.
Example request
GET /v1/vehicles/list?page=0&marketCode=ES&ecommerceReady=true
Response
{
  "info": {
    "status": "success",
    "returnedRecords": 1,
    "totalRecords": 24
  },
  "data": [
    {
      "id": "VEH-0001842",
      "configurationId": "CFG-78421",
      "marketCode": "ES",
      "status": "available"
    }
  ]
}
Vehicles

Get vehicle details

Retrieve detailed information for a specific vehicle using its identifier or configuration identifier.

GET/vehicles/details
Query parameters
vehicleIdstring
Unique vehicle identifier.
configurationIdstring
Vehicle configuration identifier.
Example request
GET /v1/vehicles/details?vehicleId=VEH-0001842
Response
{
  "info": { "status": "success" },
  "data": {
    "id": "VEH-0001842",
    "configurationId": "CFG-78421",
    "marketCode": "ES",
    "status": "available",
    "ecommerceReady": true
  }
}
Vehicles

Search vehicles

Search the vehicle inventory using a free-text query and optional market filter.

GET/vehicles/search
Query parameters
querystringrequired
Free-text search term.
marketCodestring
Optional market filter.
pageinteger
Zero-based page number.
Example request
GET /v1/vehicles/search?query=available%20vehicle&marketCode=ES
Response
{
  "info": {
    "status": "success",
    "returnedRecords": 2,
    "totalRecords": 2
  },
  "data": [
    { "id": "VEH-0001842", "status": "available" },
    { "id": "VEH-0001921", "status": "available" }
  ]
}
Documentation note: the search endpoint is a portfolio adaptation. The supplied source specification contains vehicle list and detail endpoints, but no /search path. It is intentionally separated from the source implementation rather than presented as an original endpoint.

Errors

The API communicates request failures through standard HTTP status codes.

StatusMeaningTypical cause
400Bad RequestInvalid or missing query parameter.
401UnauthorizedMissing or invalid bearer token.
403ForbiddenThe token does not have permission for the requested resource.
404Not FoundThe requested vehicle does not exist.
500Server ErrorUnexpected service failure.
